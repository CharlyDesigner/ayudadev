Python es un gran primer lenguaje porque su sintaxis es clara y sirve para muchas cosas: scripts, datos, web e inteligencia artificial. Esta ruta se enfoca en el cimiento que todas esas áreas comparten: programar bien y manejar datos.

## Cómo seguirla

- **Escribe cada ejemplo.** No copies y pegues, aunque parezca lento.
- **Haz los retos con las pistas en orden.** Si abres la solución, vuelve a escribirla desde cero al día siguiente.
- **Aprende SQL con datos propios.** Inventa tablas con tus gastos, tus libros o tus partidos favoritos.
- **Usa IA para entender, no para saltarte el esfuerzo.** Mira [Pide ejercicios a tu nivel](/ia/aprende/pedir-ejercicios-a-tu-nivel/).
- **Cuando quieras ir más lejos**, la ruta [Claude y Claude Code, de cero a avanzado](/rutas/claude-y-claude-code-de-cero-a-avanzado/) te enseña a trabajar con un agente sobre tus proyectos.

## Errores comunes de esta ruta

- **Saltar directo a librerías de datos o de IA.** Sin entender listas, diccionarios y funciones, todo se vuelve magia.
- **Evitar SQL porque "ya hay librerías".** Muchas librerías generan SQL por debajo. Saber leerlo te evita sorpresas.
- **Armar consultas pegando texto del usuario.** Usa siempre parámetros. Lee [Seguridad web y OWASP](/fundamentos/seguridad-web-owasp/).
- **Guardar datos personales en el repositorio.** Agrega los archivos de datos a `.gitignore`.
- **Olvidar las pruebas.** Escribe al menos algunas con `pytest` en el último proyecto.

## Cómo saber que estás listo para el siguiente nivel

Puedes pasar a análisis de datos, automatización avanzada o IA cuando, sin ayuda, logres: leer un CSV y resumirlo, guardar y consultar datos en SQLite, escribir funciones con pruebas, organizar un proyecto con Git y explicar tu código a otra persona. Después, explora el [catálogo de recursos de IA y datos](/biblioteca/inteligencia-artificial/) y los [fundamentos de bases de datos relacionales](/fundamentos/bases-de-datos-relacionales/).
