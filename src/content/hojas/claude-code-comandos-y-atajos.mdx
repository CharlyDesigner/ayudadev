## Instalar y abrir

| Comando | Qué hace |
| --- | --- |
| `irm https://claude.ai/install.ps1 \| iex` | Instala en Windows (PowerShell) |
| `curl -fsSL https://claude.ai/install.sh \| bash` | Instala en macOS, Linux o WSL |
| `claude --version` | Comprueba la instalación |
| `claude` | Abre una sesión interactiva en la carpeta actual |
| `claude "tarea"` | Abre una sesión con un primer mensaje |
| `claude -p "pregunta"` | Una consulta y sale (sirve para scripts) |
| `claude -c` | Continúa la conversación más reciente de esta carpeta |
| `claude -r` | Elige una conversación anterior |
| `claude --model opus` | Abre con un modelo o alias concreto |
| `claude --permission-mode plan` | Abre en un modo de permisos concreto |

## Modos de permisos

| Modo | Qué corre sin preguntar |
| --- | --- |
| `default` (Manual) | Solo lecturas |
| `acceptEdits` | Lecturas, ediciones y comandos comunes de archivos |
| `plan` | Lecturas; no edita hasta aprobar un plan |
| `auto` | Casi todo, con un clasificador que revisa |
| `dontAsk` | Solo lo preaprobado; lo demás se niega |
| `bypassPermissions` | Todo; solo en contenedores o VM aisladas |

## Reglas de permisos (settings.json)

```json
{
  "permissions": {
    "allow": ["Bash(npm run *)", "Bash(git commit *)"],
    "ask": ["Bash(git push *)"],
    "deny": ["Read(./.env)", "Bash(rm -rf *)"]
  }
}
```

Orden de evaluación: denegar, preguntar, permitir. Pon el `*` después del subcomando.

## Dónde va cada cosa

| Qué | Dónde |
| --- | --- |
| Instrucciones del proyecto | `CLAUDE.md` o `.claude/CLAUDE.md` |
| Tus instrucciones personales | `~/.claude/CLAUDE.md` |
| Notas locales del proyecto (no se suben) | `CLAUDE.local.md` |
| Reglas por carpeta o archivo | `.claude/rules/*.md` con `paths` en el encabezado |
| Skill del proyecto | `.claude/skills/<nombre>/SKILL.md` |
| Skill personal | `~/.claude/skills/<nombre>/SKILL.md` |
| Subagente del proyecto | `.claude/agents/<nombre>.md` |
| Subagente personal | `~/.claude/agents/<nombre>.md` |
| Hooks y permisos del proyecto | `.claude/settings.json` |
| Hooks y permisos solo tuyos | `.claude/settings.local.json` o `~/.claude/settings.json` |
| Servidores MCP del proyecto | `.mcp.json` |

## MCP en la terminal

```bash
claude mcp add --transport http <nombre> <url>      # remoto
claude mcp add --transport stdio <nombre> -- <cmd>  # local
claude mcp list
claude mcp get <nombre>
claude mcp remove <nombre>
```

Alcances: `--scope local` (por defecto), `project` (`.mcp.json`) y `user`.

## Hooks: lo esencial

| Dato | Valor |
| --- | --- |
| Eventos frecuentes | `PreToolUse`, `PostToolUse`, `UserPromptSubmit`, `Notification`, `Stop`, `SessionStart` |
| Entrada | JSON por stdin (`tool_name`, `tool_input`) |
| Código de salida `0` | Todo bien, sigue |
| Código de salida `2` | Bloquea y manda stderr a Claude |
| Otro código | Error que no bloquea |
