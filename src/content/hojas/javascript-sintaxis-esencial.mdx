La sintaxis de JavaScript moderno (ES2015 en adelante) para copiar y pegar. Probada con Node 24.

## Variables

| Sintaxis | Detalle |
| --- | --- |
| `const x = 1;` | No se puede reasignar. Úsala por defecto |
| `let x = 1;` | Se puede reasignar. Solo existe dentro de su bloque |
| `var x = 1;` | Forma antigua, con alcance de función. Evítala |

`const` no congela el contenido: `const a = []; a.push(1)` es válido. Lo que no puedes es hacer `a = otra`.

## Tipos

```js
typeof 5           // 'number'
typeof "a"         // 'string'
typeof true        // 'boolean'
typeof undefined   // 'undefined'
typeof null        // 'object'  (error histórico del lenguaje)
typeof {}          // 'object'
typeof []          // 'object'  (usa Array.isArray)
typeof (() => 1)   // 'function'
typeof 10n         // 'bigint'
typeof Symbol()    // 'symbol'
```

Son falsos (`falsy`): `false`, `0`, `""`, `null`, `undefined` y `NaN`. Todo lo demás es verdadero, incluidos `[]`, `{}` y `"0"`.

## Operadores

| Expresión | Resultado |
| --- | --- |
| `7 / 2` | `3.5` (no hay división entera: usa `Math.floor(7 / 2)`) |
| `7 % 2` | `1` |
| `-7 % 3` | `-1` (el signo sigue al dividendo) |
| `2 ** 10` | `1024` |
| `0.1 + 0.2` | `0.30000000000000004` |
| `1 == "1"` | `true` (convierte tipos) |
| `1 === "1"` | `false` (comparación estricta; úsala siempre) |
| `null == undefined` | `true` |
| `NaN === NaN` | `false`. Usa `Number.isNaN(x)` |
| `"5" + 2` | `'52'` (concatena) |
| `"5" - 2` | `3` (convierte a número) |
| `n > 3 ? "grande" : "chico"` | Ternario |
| `a \|\| "def"` | `a` si es verdadero, si no `"def"` |
| `a ?? "def"` | `a` si no es `null` ni `undefined` (conserva `0` y `""`) |
| `obj?.a?.b` | Acceso seguro: `undefined` si algo falta |
| `x ??= 5`, `x \|\|= 5`, `x &&= 5` | Asignaciones lógicas |

```js
0 || "def"      // 'def'
0 ?? "def"      // 0
null ?? "def";   // 'def'
({}).a?.b       // undefined, sin error
```

## Números y texto

| Expresión | Resultado |
| --- | --- |
| `parseInt("42px")` | `42` |
| `parseInt("101", 2)` | `5` |
| `Number("42px")` | `NaN` |
| `Number("")` | `0` |
| `+"3.5"` | `3.5` |
| `(255).toString(16)` | `'ff'` |
| `(3.14159).toFixed(2)` | `'3.14'` (devuelve texto) |
| `Number.isInteger(5)` | `true` |
| `Math.round(2.5)`, `Math.round(-2.5)` | `3`, `-2` |
| `Math.floor(-1.1)`, `Math.trunc(-2.7)` | `-2`, `-2` |
| `Math.max(...[1, 5, 3])` | `5` |
| `Number.MAX_SAFE_INTEGER` | `9007199254740991`. Para más, usa `BigInt` (`10n ** 20n`) |

```js
const nombre = "Ana";
`Hola ${nombre}, ${2 * 5}`        // 'Hola Ana, 10' (plantilla con backticks)
```

| Método de texto | Resultado |
| --- | --- |
| `"hola".at(-1)` | `'a'` |
| `"hola".slice(1, 3)` | `'ol'` |
| `"a-b-c".split("-")` | `['a', 'b', 'c']` |
| `"abc".includes("b")` | `true` |
| `"  x ".trim()` | `'x'` |
| `"ab".padStart(4, "*")` | `'**ab'` |
| `"ab".repeat(2)` | `'abab'` |
| `"hola".replaceAll("o", "0")` | `'h0la'` |
| `"x".localeCompare("y")` | `-1` (comparar con acentos) |

## Funciones

```js
function resta(a, b) { return a - b; }       // declaración (se eleva: puedes llamarla antes)
const suma = (a, b = 0) => a + b;            // flecha, con valor por defecto
const doble = (n) => n * 2;                  // retorno implícito sin llaves
const obj = () => ({ ok: true });            // para devolver un objeto, ponlo entre paréntesis
const cuenta = (...args) => args.length;     // parámetros rest
cuenta(1, 2, 3);                             // 3
```

## Desestructuración y spread

```js
const { a, b = 9, ...resto } = { a: 1, c: 3, d: 4 };
// a = 1, b = 9, resto = { c: 3, d: 4 }

const [p, , q = 7, ...r] = [1, 2, undefined, 4, 5];
// p = 1, q = 7, r = [4, 5]

[...[1, 2], 3];               // [1, 2, 3]
({ ...{ a: 1 }, b: 2 })      // { a: 1, b: 2 }
```

## Condicionales y bucles

```js
if (n > 10) { /* ... */ } else if (n > 3) { /* ... */ } else { /* ... */ }

switch (n) {
  case 5: console.log("cinco"); break;   // sin break, sigue al siguiente case
  default: console.log("otro");
}

for (let i = 0; i < 3; i++) { }
for (const x of [10, 20]) { }                 // valores de un iterable
for (const k in { a: 1, b: 2 }) { }           // claves de un objeto
for (const [k, v] of Object.entries({ a: 1 })) { }
while (cond) { }
```

| Palabra | Efecto |
| --- | --- |
| `break` | Sale del bucle |
| `continue` | Salta a la siguiente vuelta |
| `break etiqueta`, `continue etiqueta` | Igual, sobre un bucle exterior con nombre |

<Callout tipo="warning" titulo="for...in con arreglos">

`for (const i in arreglo)` recorre los índices como texto y puede incluir propiedades heredadas. Para arreglos usa `for...of`.

</Callout>

## Clases

```js
class Animal {
  #secreto = 1;                 // campo privado
  static creados = 0;           // campo estático
  constructor(nombre) {
    this.nombre = nombre;
    Animal.creados++;
  }
  hablar() { return `${this.nombre} hace ruido`; }
  get sec() { return this.#secreto; }
}

class Perro extends Animal {
  hablar() { return super.hablar() + " (guau)"; }
}

new Perro("Rex").hablar();      // 'Rex hace ruido (guau)'
```

## Asincronía: promesas y async/await

```js
const esperar = (ms) => new Promise((resolver) => setTimeout(resolver, ms));

async function main() {
  await esperar(10);
  const [x, y] = await Promise.all([1, Promise.resolve(2)]);   // en paralelo
  try {
    await Promise.reject(new Error("falló"));
  } catch (e) {
    console.log(e.message);     // 'falló'
  }
}
main().then(() => console.log("listo"));
```

| Función | Resultado |
| --- | --- |
| `Promise.all([...])` | Espera todas. Falla si una falla |
| `Promise.allSettled([...])` | Espera todas; da el estado de cada una (`fulfilled` o `rejected`) |
| `Promise.race([...])` | La primera en terminar, con éxito o error |
| `Promise.any([...])` | La primera que tenga éxito |
| `fetch(url)` | Petición HTTP; devuelve una promesa de `Response` |

```js
const r = await fetch("https://api.github.com/zen");
if (!r.ok) throw new Error(`HTTP ${r.status}`);   // fetch no falla con 404 o 500
const texto = await r.text();                      // o await r.json()
```

Orden de ejecución: primero todo el código síncrono, luego las microtareas (`.then`, `await`), después los temporizadores (`setTimeout`). Por eso `Promise.resolve().then(...)` corre antes que `setTimeout(..., 0)`.

## JSON

| Expresión | Resultado |
| --- | --- |
| `JSON.stringify({ a: 1, b: [1, 2], c: undefined })` | `'{"a":1,"b":[1,2]}'` (omite `undefined` y funciones) |
| `JSON.stringify(obj, null, 2)` | Con sangría de 2 espacios |
| `JSON.parse('{"x":[1]}')` | `{ x: [1] }` |

## Módulos

```js
// util.js
export const PI = 3.14;
export default function saludar() { return "hola"; }

// app.js
import saludar, { PI } from "./util.js";
```

Para usar `import` en Node, el archivo debe ser `.mjs` o el `package.json` debe tener `"type": "module"`.

## Trampas frecuentes

| Trampa | Qué pasa |
| --- | --- |
| `[10, 9, 1].sort()` | Ordena como texto: `[1, 10, 9]`. Usa `.sort((a, b) => a - b)` |
| `["1", "2", "3"].map(parseInt)` | `[1, NaN, NaN]`. Usa `.map(Number)` |
| `[] + []` | `''` (cadena vacía) |
| `0.1 + 0.2 === 0.3` | `false`. Compara con una tolerancia |
| Modificar `Object.freeze` en modo estricto | Lanza `TypeError`; fuera del modo estricto falla en silencio |
| `typeof null` | `'object'` |
| `var` y elevación | `var v = 1` se eleva: antes de esa línea `v` vale `undefined` |
