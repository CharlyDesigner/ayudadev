## Qué vas a construir

Un programa que se usa así:

```bash
node notas.mjs agregar Comprar pilas
node notas.mjs agregar Estudiar closures
node notas.mjs listar
node notas.mjs buscar closures
node notas.mjs borrar 1
```

Las notas se guardan en un archivo `notas.json`, así que siguen ahí cuando cierras la terminal. Es un proyecto pequeño, pero practica lo que hace cualquier programa real: recibir entradas, leer y escribir datos, validar y mostrar errores claros.

## Requisitos

- Saber usar una terminal básica: [Terminal explicada](/fundamentos/terminal-explicada/).

Esta versión la probamos con los comandos de arriba. Guárdala como `notas.mjs`.

```js
// Gestor de notas en la terminal. Uso: node notas.mjs <comando> [texto]
import { readFile, writeFile } from 'node:fs/promises';

const ARCHIVO = new URL('./notas.json', import.meta.url);

async function leer() {
  try {
    return JSON.parse(await readFile(ARCHIVO, 'utf8'));
  } catch (error) {
    if (error.code === 'ENOENT') return []; // primera vez: aún no hay archivo
    throw error;
  }
}

async function guardar(notas) {
  await writeFile(ARCHIVO, JSON.stringify(notas, null, 2) + '\n', 'utf8');
}

const [comando, ...resto] = process.argv.slice(2);
const texto = resto.join(' ').trim();
const notas = await leer();

switch (comando) {
  case 'agregar': {
    if (!texto) {
      console.error('Escribe el texto de la nota. Ejemplo: node notas.mjs agregar Comprar pilas');
      process.exit(1);
    }
    const id = notas.reduce((mayor, n) => Math.max(mayor, n.id), 0) + 1;
    notas.push({ id, texto });
    await guardar(notas);
    console.log(`Nota ${id} guardada.`);
    break;
  }
  case 'listar': {
    if (notas.length === 0) console.log('No tienes notas.');
    for (const n of notas) console.log(`${n.id}. ${n.texto}`);
    break;
  }
  case 'buscar': {
    const encontradas = notas.filter((n) => n.texto.toLowerCase().includes(texto.toLowerCase()));
    if (encontradas.length === 0) console.log('Sin resultados.');
    for (const n of encontradas) console.log(`${n.id}. ${n.texto}`);
    break;
  }
  case 'borrar': {
    const id = Number(texto);
    if (!notas.some((n) => n.id === id)) {
      console.error(`No existe la nota ${texto}.`);
      process.exit(1);
    }
    await guardar(notas.filter((n) => n.id !== id));
    console.log(`Nota ${id} borrada.`);
    break;
  }
  default:
    console.log('Comandos: agregar <texto> | listar | buscar <texto> | borrar <id>');
}
```

Una sesión de prueba:

```text
$ node notas.mjs listar
No tienes notas.
$ node notas.mjs agregar Comprar pilas
Nota 1 guardada.
$ node notas.mjs agregar Estudiar closures
Nota 2 guardada.
$ node notas.mjs buscar CLOS
2. Estudiar closures
$ node notas.mjs borrar 9
No existe la nota 9.
```

Detalles que conviene entender:

- `import.meta.url` hace que `notas.json` viva junto al programa, sin importar desde qué carpeta lo ejecutes.
- El `try/catch` solo trata el error de "archivo inexistente" (`ENOENT`) y relanza cualquier otro, para no esconder fallos reales.
- El `id` se calcula con el mayor existente más uno. Si usaras la longitud del arreglo, al borrar y agregar se repetirían ids.
- `process.exit(1)` indica error a quien ejecute el programa (otros scripts, por ejemplo).
- Usamos `.mjs` para poder usar `await` al nivel superior.
