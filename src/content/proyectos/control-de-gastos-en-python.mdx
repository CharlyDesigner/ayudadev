## Qué vas a construir

Un programa de terminal para llevar tus gastos:

```bash
python gastos.py agregar 85.50 "Tacos" --categoria comida
python gastos.py agregar 120 "Camión" --categoria transporte
python gastos.py listar
python gastos.py resumen
```

Los datos se guardan en un archivo `gastos.db` de SQLite, que viene incluido con Python. Es un proyecto ideal para unir dos cosas que a veces se aprenden separadas: un lenguaje (Python) y una base de datos (SQL).

```python
"""Control de gastos en la terminal con SQLite.

Uso:
  python gastos.py agregar 85.50 "Tacos" --categoria comida
  python gastos.py listar
  python gastos.py resumen
"""
import argparse
import sqlite3
from datetime import date

BASE = "gastos.db"


def conectar():
    con = sqlite3.connect(BASE)
    con.execute(
        """CREATE TABLE IF NOT EXISTS gastos (
             id        INTEGER PRIMARY KEY,
             fecha     TEXT NOT NULL,
             concepto  TEXT NOT NULL,
             categoria TEXT NOT NULL,
             monto     REAL NOT NULL CHECK (monto > 0)
           )"""
    )
    return con


def agregar(args):
    with conectar() as con:  # el "with" confirma (commit) los cambios al salir
        con.execute(
            "INSERT INTO gastos (fecha, concepto, categoria, monto) VALUES (?, ?, ?, ?)",
            (args.fecha, args.concepto, args.categoria, args.monto),
        )
    print(f"Guardado: {args.concepto} (${args.monto:.2f})")


def listar(_args):
    con = conectar()
    filas = con.execute("SELECT id, fecha, concepto, categoria, monto FROM gastos ORDER BY fecha, id")
    for id_, fecha, concepto, categoria, monto in filas:
        print(f"{id_:>3}  {fecha}  {concepto:<12} {categoria:<10} ${monto:>8.2f}")


def resumen(_args):
    con = conectar()
    filas = con.execute(
        "SELECT categoria, SUM(monto) AS total FROM gastos GROUP BY categoria ORDER BY total DESC"
    )
    for categoria, total in filas:
        print(f"{categoria:<10} ${total:>8.2f}")


def main():
    parser = argparse.ArgumentParser(description="Control de gastos")
    sub = parser.add_subparsers(dest="comando", required=True)

    p = sub.add_parser("agregar", help="Registra un gasto")
    p.add_argument("monto", type=float)
    p.add_argument("concepto")
    p.add_argument("--categoria", default="otros")
    p.add_argument("--fecha", default=date.today().isoformat())
    p.set_defaults(funcion=agregar)

    sub.add_parser("listar", help="Muestra todos los gastos").set_defaults(funcion=listar)
    sub.add_parser("resumen", help="Total por categoría").set_defaults(funcion=resumen)

    args = parser.parse_args()
    args.funcion(args)


if __name__ == "__main__":
    main()
```

Una sesión de prueba (con fechas indicadas para que sea reproducible):

```text
$ python gastos.py agregar 85.50 Tacos --categoria comida --fecha 2026-10-01
Guardado: Tacos ($85.50)
$ python gastos.py agregar 120 Camión --categoria transporte --fecha 2026-10-02
$ python gastos.py agregar 60 Café --categoria comida --fecha 2026-10-03
$ python gastos.py listar
  1  2026-10-01  Tacos        comida     $   85.50
  2  2026-10-02  Camión       transporte $  120.00
  3  2026-10-03  Café         comida     $   60.00
$ python gastos.py resumen
comida     $  145.50
transporte $  120.00
```

Si intentas registrar un monto negativo, la base lo rechaza con `CHECK constraint failed: monto > 0`. Todavía se muestra como error técnico: convertirlo en un mensaje amigable es uno de los retos extra.

Detalles que conviene entender:

- Los `?` en el `INSERT` son **parámetros**. SQLite los separa del código SQL y así evitas la inyección SQL. Consulta [Seguridad web y OWASP](/fundamentos/seguridad-web-owasp/).
- `with conectar() as con` confirma los cambios al terminar. El programa es corto y se cierra enseguida; en una app larga cerrarías la conexión con `con.close()`.
- Un `float` sirve para practicar, pero para dinero real es mejor guardar centavos como enteros o usar `Decimal`.
